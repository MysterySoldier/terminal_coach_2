# Terminal Coach — Over Your Shoulder

Standalone Linux Terminal Coach (`https://coach.mysterylabs.dev`).

- **Truthful shell engine**: real filesystem permissions (`chmod`/`chown`), archives (`tar -c` / `tar -x`), process table (`ps` / `kill`), `df -i`, pipes, globs, and systemd reboot persistence.
- **16 sysadmin jobs** across **4 modes** (`Easy`, `Medium`, `Hard`, `Extreme`) with separate localStorage progress (`coachEasyProgress`, `coachMediumProgress`, `coachProgress`, `coachExtremeProgress`).
- **Kokoro `af_heart` voice**: 866 pre-baked offline MP3 clips (`web/public/audio/`).

## Commands

```bash
cd web
npm install
npm run test
npm run test:browser
npm run build
```
